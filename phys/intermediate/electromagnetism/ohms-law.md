## オームの法則

金属線に加える電圧を変えながら流れる電流を測定すると、電圧と電流は比例することが分かります。この比例定数を**電気抵抗**（単位：オーム、記号$\Omega$）といい、次の関係を**オームの法則**といいます。

$$V = IR$$

$V$は電圧（$\mathrm{V}$）、$I$は電流（$\mathrm{A}$）、$R$は抵抗（$\Omega$）です。抵抗が大きいほど、同じ電圧で流れる電流は小さくなります。

> [!NOTE]
> オームの法則は、温度が一定に保たれる金属導体（オーム抵抗体）で成り立つ関係です。豆電球のフィラメントのように、電流によって温度が大きく変化する物体では、電圧と電流は比例しません。

**例題**：$6\ \mathrm{V}$の電圧を$3\ \Omega$の抵抗に加えたときに流れる電流を求める。

$$I = \frac{V}{R} = \frac{6\ \mathrm{V}}{3\ \Omega} = 2\ \mathrm{A}$$

**抵抗の値は、物質の種類によって異なります。** 銅やアルミニウムなどの金属は抵抗が小さく電流を通しやすい一方、ゴムやガラスなどは抵抗がとても大きく、電流をほとんど通しません。同じ金属でも、導線が細く長いほど抵抗は大きくなります。これは、電流の通り道が長いほど電子が流れにくくなり、太い（断面積が大きい）ほど電子が流れやすくなるためです。

## 抵抗の直列つなぎ

2つの抵抗を直列につなぐと、電流はどちらの抵抗にも同じ大きさで流れ、全体にかかる電圧は各抵抗にかかる電圧の和になります。全体を流れる電流を$I$とすると、各抵抗にかかる電圧はそれぞれ$IR_1$、$IR_2$なので、

$$V = V_1 + V_2 = IR_1 + IR_2 = I(R_1 + R_2)$$

両辺を$I$で割ると、直列つなぎの合成抵抗$R$は、各抵抗の和になることが分かります。

$$R = R_1 + R_2$$

直列につなぐほど、合成抵抗は大きくなります。

**例題**：$2\ \Omega$と$3\ \Omega$の抵抗を直列につなぐと、合成抵抗は $R=2+3=5\ \Omega$。

## 抵抗の並列つなぎ

2つの抵抗を並列につなぐと、各抵抗には同じ電圧がかかり、全体を流れる電流は各抵抗を流れる電流の和になります。各抵抗にかかる電圧を$V$とすると、各抵抗を流れる電流はそれぞれ$\dfrac{V}{R_1}$、$\dfrac{V}{R_2}$なので、

$$I = I_1 + I_2 = \frac{V}{R_1} + \frac{V}{R_2} = V\left(\frac{1}{R_1} + \frac{1}{R_2}\right)$$

$I = \dfrac{V}{R}$との対応から、並列つなぎの合成抵抗$R$は、次の関係を満たすことが分かります。

$$\frac{1}{R} = \frac{1}{R_1} + \frac{1}{R_2}$$

並列につなぐほど、合成抵抗は各抵抗より小さくなります。

**例題**：$2\ \Omega$と$3\ \Omega$の抵抗を並列につなぐと、$\dfrac{1}{R}=\dfrac{1}{2}+\dfrac{1}{3}=\dfrac{5}{6}$ より $R=\dfrac{6}{5}=1.2\ \Omega$。

## まとめ

金属線を流れる電流は加えた電圧に比例し、その比例定数が抵抗です（オームの法則 $V=IR$）。抵抗を直列につなぐと合成抵抗は各抵抗の和になり、並列につなぐと合成抵抗は各抵抗より小さくなります。
