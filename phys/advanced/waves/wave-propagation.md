## 波面とホイヘンスの原理

波が伝わるとき、同じ位相（同じ振動の状態）にある点を結んだ面（線）を**波面**といいます。ある時刻の波面上のすべての点が、それぞれ新たな波（**素元波**）の波源になり、これらの素元波に共通に接する面が、次の瞬間の波面になる——という考え方を**ホイヘンスの原理**といいます。

具体的に、平面波が速さ$v$で直進する場合を考えます。ある時刻の波面（直線）上に間隔を空けていくつか点を取り、それぞれの点を中心として半径$v\Delta t$の円を描きます（波が3次元空間を伝わる場合は球面になります）。波面が直線であれば、隣り合う点から描いた円はすべて同じ1本の直線に接し、その直線はもとの波面と平行で、もとの波面から$v\Delta t$だけ進んだ位置にあります。この、無数の素元波に共通に接する面（**包絡面**）が、時間$\Delta t$後の新しい波面になります。

ホイヘンスの原理を使うと、波面が障害物の端を回り込む様子（回折）や、境界面で反射・屈折する様子を、作図によって説明できます。

## 水面波の反射・屈折

水面波を使った実験水槽で、波が壁に当たる様子を観察すると、入射波と反射波で入射角と反射角が等しくなることが確かめられます（反射の法則）。また、水深が変わる境界を波が通過すると、水深が浅いところでは波の伝わる速さが遅くなるため、屈折が起こることが確かめられます。これらは、中級編で学んだ光の反射・屈折と同じ規則性であり、ホイヘンスの原理によって統一的に説明できます。

### 反射の法則の導出

境界に斜めに入射する波面上に2点P、Qをとり、点Pがちょうど境界上の点に達した瞬間を考えます（このとき点Qはまだ境界に届いていません）。点Qが境界上の点Rに達するまでの時間を$\Delta t$とすると、その間に点Qは速さ$v$で距離$QR = v\Delta t$だけ進みます。

一方、点Pはこの$\Delta t$の間も素元波源として波を送り出し続けており、同じ速さ$v$で半径$PS = v\Delta t$の円（波面）まで広がっています。点Rからこの円に引いた接線（接点をSとする）が、反射後の新しい波面になります。

入射角$\theta_1$を入射波面PQと境界PRのなす角（三角形PQRの頂点Pにおける角）、反射角$\theta_2$を反射波面RSと境界PRのなす角（三角形PSRの頂点Rにおける角）とすると、直角三角形PQR・PSRについてそれぞれ

$$QR = PR\sin\theta_1 = v\Delta t, \qquad PS = PR\sin\theta_2 = v\Delta t$$

が成り立ちます。両式の右辺が等しいことから$PR\sin\theta_1 = PR\sin\theta_2$、すなわち$\sin\theta_1 = \sin\theta_2$となり、$\theta_1 = \theta_2$、つまり入射角と反射角が等しいという反射の法則が導かれます。

### 屈折の法則の導出

水深が変わる境界（水深が深い側を速さ$v_1$、浅い側を速さ$v_2$で波が伝わるとする）に、波面が斜めに入射する場合を考えます。反射のときと同様に波面上に2点P、Qをとり、点Pがちょうど境界に達した瞬間から、点Qが境界上の点Rに達するまでの時間を$\Delta t$とすると、点Qは速さ$v_1$の側を進むので$QR = v_1\Delta t$です。

一方、点Pは境界を越えた直後から速さ$v_2$の側で素元波源として波を送り出すため、時間$\Delta t$後には半径$PS = v_2\Delta t$の円まで広がっています。点Rからこの円に引いた接線（接点をS）が、屈折後の新しい波面になります。

入射角$\theta_1$（入射波面PQと境界PRのなす角）、屈折角$\theta_2$（屈折波面RSと境界PRのなす角）とすると、

$$QR = PR\sin\theta_1 = v_1\Delta t, \qquad PS = PR\sin\theta_2 = v_2\Delta t$$

が成り立ちます。辺々を割って$PR$を消去すると、

$$\frac{\sin\theta_1}{\sin\theta_2} = \frac{v_1}{v_2}$$

という屈折の法則が得られます。水深が浅い側ほど速さが小さくなるため、境界を通過した波は境界の法線に近づく向きに屈折します。

### 例題

**例題（反射）**：水面波が壁に入射角$55°$で入射する。反射角を求める。

反射では速さ$v$が変化しないため、反射の法則$\theta_1 = \theta_2$がそのまま成り立つ。したがって、反射角も$55°$である。

**例題（屈折）**：入射角$\theta_1 = 30°$、$v_1 : v_2 = 2 : 1$のとき、屈折角$\theta_2$を求める。

$$\frac{\sin\theta_1}{\sin\theta_2} = \frac{v_1}{v_2} = 2 \quad\Longrightarrow\quad \sin\theta_2 = \frac{\sin 30°}{2} = \frac{1}{2}\times\frac{1}{2} = \frac{1}{4}$$

したがって、$\theta_2 = \sin^{-1}\dfrac{1}{4} \approx 14.5°$である。

## 波の式

$x$軸の正の向きに、速さ$v$、振幅$A$、周期$T$、波長$\lambda$で伝わる波を考えます。原点での媒質の変位が$y = A\sin\dfrac{2\pi}{T}t$と表される場合、位置$x$での波は原点より$\dfrac{x}{v}$だけ遅れて同じ振動をするので、時刻$t$、位置$x$での変位$y$は、次のように表されます。

$$y = A\sin\left\{2\pi\left(\frac{t}{T} - \frac{x}{\lambda}\right)\right\}$$

（$v=\lambda/T$の関係を用いて$x/v = xT/\lambda$と書き換えた）。この式を**波の式**といい、任意の時刻・位置での媒質の変位を求めることができます。

**例題**：振幅$2\ \mathrm{cm}$、周期$4\ \mathrm{s}$、波長$8\ \mathrm{cm}$の波について、$t=1\ \mathrm{s}$、$x=2\ \mathrm{cm}$での変位を求める。

$$y = 2\sin\left\{2\pi\left(\frac{1}{4}-\frac{2}{8}\right)\right\} = 2\sin(0) = 0\ \mathrm{cm}$$

## まとめ

ホイヘンスの原理は、波面上の各点を新たな波源とみなすことで、波の伝わり方を作図によって説明する考え方です。水面波の反射・屈折は、光の反射・屈折と同じ規則性に従い、ホイヘンスの原理で統一的に理解できます。波を数式で表す波の式を使うと、任意の時刻・位置での変位を計算で求められます。
